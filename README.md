SmartRoute AI — Customer Query Routing
Capstone Problem 35 — Customer Query Routing Classification
SmartRoute AI is an academic NLP prototype that classifies incoming customer-support messages into predefined service intents and applies a confidence-aware routing policy.
Final Demonstrated Configuration
Dataset: BANKING77
Training samples: 10,003
Official test samples: 3,080
Intents: 77
Model: TF-IDF + Logistic Regression
Official test accuracy from the final local run: 87.24%
Weighted precision: 88.02%
Weighted recall: 87.24%
Weighted F1-score: 87.26%
Frontend: HTML5 + CSS3 + JavaScript
Backend: Flask

Run Locally
1. Install dependencies
pip install -r requirements.txt
2. Ensure the final model is present
Place the final 77-intent model generated by the official training run at:
model/smartroute_pipeline.pkl
3. Start the application
python app.py
4. Open the application
http://127.0.0.1:5000
Dataset
BANKING77 is a fine-grained banking customer-service intent classification dataset created by PolyAI. It contains 13,083 English customer-service queries across 77 intents, with 10,003 training examples and 3,080 test examples.
Dataset: BANKING77
Dataset source: PolyAI task-specific datasets
