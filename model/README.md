Model folder
The capstone run shown in the final demo used the official BANKING77 training split (10,003 samples, 77 intents) and the official test split (3,080 samples).
For the final local submission, keep the 77-class smartroute_pipeline.pkl generated by your official training run in this folder with the exact filename:
smartroute_pipeline.pkl
The demo_model.pkl included in this package is only a fallback/demo artifact from an earlier prototype and should not be presented as the final 77-intent model.
